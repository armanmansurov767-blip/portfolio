# Заявки с портфолио → Google Таблица + письмо в Gmail

```
Форма «Обсудить сайт»  ──►  Google-скрипт  ──►  1. новая строка в таблице «Портфолио — заявки»
                                           └─►  2. письмо на armanmansurov767@gmail.com
```

- Таблица: https://drive.google.com/open?id=1Okz7Pxi6_MqRpHvxGN5S4eLSH9V7sJmvZifeKHHuXJc
- Редактор скрипта: https://script.google.com/d/11f1P_55sPDSRvcThRuMbW0MLtMLGEe8cIXlhe-HlKuHdoR2MiHcV4LeD/edit
- Адрес приёма заявок прописан в `assets/config.js` в поле `leadsEndpoint`.

Таблица и скрипт живут в аккаунте mansurovarman32@gmail.com и работают на серверах Google бесплатно.

## Первый запуск (один раз)

Пока вы не разрешите скрипту работать, заявки не принимаются.

1. Откройте редактор скрипта по ссылке выше (войдите как mansurovarman32@gmail.com).
2. Вверху выберите функцию `setup` и нажмите «Выполнить».
3. Google спросит разрешения: «Просмотреть разрешения» → выберите аккаунт → «Дополнительные настройки» →
   «Перейти на страницу проекта» → «Разрешить». Предупреждение «Приложение не проверено» нормально: это ваш собственный скрипт.
4. Таблица оформится (заголовки, статусы, цвета), а на armanmansurov767@gmail.com придёт тестовое письмо.

Проверка: откройте адрес из `leadsEndpoint` в браузере — должен прийти ответ `{"ok":true,"service":"portfolio-leads"}`.

## Как работать с заявками

- **Статус** (колонка I): Новая → Связался → Обсуждаем → Договорились / Отказ. Строка окрашивается по статусу.
- **Заметка** (колонка J) — о чём договорились с клиентом.
- В письме есть кнопки для ответа, подобранные по контакту клиента: «Написать на почту», «Написать в Telegram»
  или «Позвонить» и «Написать в WhatsApp», плюс «Открыть в таблице». Если клиент оставил почту, «Ответить» в Gmail пишет сразу ему.
- Чтобы письма получали несколько адресов, впишите их в начале `Code.gs`:
  `const NOTIFY_EMAIL = 'a@gmail.com, b@gmail.com';` — и обновите скрипт (ниже).

## Как обновить скрипт после правок в Code.gs

Скрипт связан с папкой портфолио через [clasp](https://github.com/google/clasp) (файл `.clasp.json`). Из папки `portfolio`:

```bash
npx @google/clasp push --force
```

```bash
npx @google/clasp update-deployment AKfycbxv3OaTNuD0X5vO7V1fnPqQSZQjDmShiuQlDrmNuW0bTaD-Y3SO845kL0bkehQ2humw6w
```

Адрес для сайта при этом не меняется.

## Что встроено

- **Ловушка для спам-ботов**: невидимое поле, которое заполняют только боты; такие заявки не записываются.
- **Проверка**: без имени и контакта заявка не принимается ни на сайте, ни в скрипте.
- **Защита таблицы**: текст, начинающийся с `=`, `+`, `-` или `@`, записывается как текст, а не формула.
- **Если нет связи**, форма сообщает об ошибке и предлагает отправить текст почтой или в Telegram.
- **Лимит**: бесплатный Gmail отправляет через скрипт до 100 писем в сутки. Строки в таблицу пишутся всегда.
