# Портфолио — Арман Мансуров

Сайт-портфолио с тремя работами: «листва.», Halden и Vela 14. Обычный HTML, CSS и JavaScript — без сборки.
Прокрутка и анимация на GSAP ScrollTrigger и Lenis, библиотеки и шрифты грузятся из сети.

Работы живут на поддоменах: `listva.`, `halden.` и `vela.armanmansurovportfolio.website`. Страницы работ и главная ссылаются на них и встраивают их в окна.

## Как открыть

```bash
npx http-server -p 5540 -c-1
```

и перейдите на http://localhost:5540 (команду запускать из папки `portfolio`).

## Языки

Сайт на русском (основной), английском и казахском. Переключатель `RU / EN / KZ` в шапке, на телефоне — в меню.

- Русский текст остаётся в HTML как есть и служит ключом: в `assets/i18n.js` для каждой русской фразы записан перевод. Правите фразу в HTML — поправьте и её ключ в словаре, иначе на странице останется русский. Какие фразы остались без перевода: открыть страницу с `?lang=en` и ввести в консоли `I18N.missing`.
- Язык выбирается так: `?lang=en` в адресе (ссылкой можно делиться) → сохранённый выбор → язык браузера → русский.
- Окна и ссылки на сайты работ получают `?lang=` с языком портфолио: сами сайты (Листва, Halden, Vela 14) тоже на трёх языках, у каждого свой переключатель.
- Не переводятся: названия работ; демо-бот Halden (настоящий бот говорит по-русски); окна-макеты в «сайте в разборе»; вкладки браузера в окнах работ; скриншоты работ (они русские).
- Письмо в «Обсудить сайт» собирается на языке страницы, а в Google Таблицу уходят русские значения, как раньше.

## Если работа изменилась

Правки в самой работе (её репозиторий) выкатываются сами: портфолио показывает живой сайт с поддомена. Скриншоты в `assets/shots/` остаются прежними — их нужно переснять отдельно.
