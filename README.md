# Портфолио — Арман Мансуров

Сайт-портфолио с тремя работами: «листва.», Halden и Vela 14. Обычный HTML, CSS и JavaScript — без сборки.
Прокрутка и анимация на GSAP ScrollTrigger и Lenis, библиотеки и шрифты грузятся из сети.

## Как открыть

```bash
npx http-server -p 5540 -c-1
```

и перейдите на http://localhost:5540 (команду запускать из папки `portfolio`).

## Страницы

| Файл | Что внутри |
|---|---|
| `index.html` | Главная: сцена, где три сайта листаются вместе со страницей; с чем помогаю; демо Telegram-бота Halden; сайт в разборе на слои; шаги работы |
| `listva.html`, `halden.html`, `vela.html` | Страница работы: живой сайт в окне (компьютер и телефон), что в нём сделано |
| `contact.html` | «Обсудить сайт»: из ответов собирается письмо |

## Что где лежит

| Файл | Что в нём |
|---|---|
| `assets/config.js` | Имя и контакты: почта, Telegram, WhatsApp. Меняются только здесь |
| `assets/site.css` | Всё оформление. Палитры работ — блоки `[data-theme="…"]` в начале файла |
| `assets/site.js` | Шапка, меню, подвал, плавная прокрутка |
| `assets/home.js` | Сцена главной и разбор на слои |
| `assets/case.js` | Живой сайт в окне на страницах работ |
| `assets/contact.js` | Сборка письма |
| `assets/botdemo.js` | Демо Telegram-бота Halden с тестом «куда поехать». Повторяет `telegram-bot/bot.js` из репозитория Halden: если бот меняется, демо нужно поправить вручную |
| `assets/reviews.js` | Отзывы клиентов. Пока список пуст, блока отзывов на сайте нет |
| `assets/shots/` | Скриншоты работ для сцены и обложек |
| `sites/` | Копии трёх сайтов, чтобы портфолио открывалось одной папкой |

## Если работа изменилась

Копии в `sites/` сами не обновляются. После правок в исходных сайтах:

```bash
node sync-sites.mjs
```

Скриншоты в `assets/shots/` при этом остаются прежними — их нужно переснять отдельно.

## Важно

- Письмо с «Обсудить сайт» уходит через почтовую программу или мессенджер посетителя: своего сервера у портфолио нет.
- Формы внутри «листвы» и Halden настоящие: заявки, отправленные из окна в портфолио, попадут в их Google Таблицы.
- «листва.», Halden и Vela 14 — концепты, компании в них вымышлены. В подвале это указано.
